# Taiwan Wildlife Explorer

原生 HTML / CSS / ES modules 的桌面版第一階段雛形，無建置步驟、無第三方套件。

## 本機預覽

在專案根目錄執行 `python3 -m http.server 8000`，使用瀏覽器開啟 http://localhost:8000 。請透過 HTTP 開啟，直接雙擊 HTML 可能受到 ES modules 的來源限制。

## 操作

滾輪或 ＋／− 縮放，拖曳地圖，⌖ 重設。145% 起顯示動物標記，點選後更新研究面板、解鎖圖鑑及紀錄。圖鑑採單欄原位展開，一次展開一張。研究員檔案可修改稱呼與確認後重置進度。所有狀態只存記憶體。

## 檔案

`index.html` 定義版面；`styles/main.css` 定義視覺；`scripts/main.js` 連接地圖、研究面板、圖鑑及對話框。五種物種集中於 `scripts/data/animals.js`，`state.js` 管理暫存狀態。參考圖為 `design-reference/exploration-layout.jpg`、`encyclopedia-layout.jpg`、`encyclopedia-detail.jpg`。

## 素材與資料限制

地圖是 SVG 臨時輪廓示意，並非可用於定位的正式台灣地圖。所有棲地座標均未校準。動物標記暫用系統 Emoji，並非正式一致風格插畫；各平台外觀可能不同。研究面板及圖鑑明示照片待提供，未使用其他動物照片代替。動物文字為待校核的示範資料，保育分級未提供。

後續：正式地圖、物種照片與來源授權、2D 動物插畫、資料與位置校核、開場動畫、完整發現動畫、localStorage、完整 RWD。正式照片整合時可使用集中資料的 photo 欄位並擴充 research-panel.js 的共用素材函式。

## 視窗高度與捲動

探索區與圖鑑區各為 `100dvh`（`100vh` 作為舊瀏覽器退路），以 Grid 分配標題、操作列與剩餘內容空間。地圖不再使用固定 520px／590px 高度。研究面板和圖鑑列表可獨立捲動，圖鑑展開維持原位，不增加整頁高度。圖鑑定位連結對齊第二區頂部。

區塊最低高度為 600px；更矮的視窗改由整頁捲動提供操作空間。沒有啟用 scroll-snap，避免影響地圖滾輪和列表捲動。可使用 Tab 聚焦列表或研究面板，再使用鍵盤捲動。

高度調整已完成靜態尺寸預算與既有互動回歸檢查；目前環境無法存取瀏覽器，1440×900 與 1366×768 的實際瀏覽器視覺驗收仍待執行。
