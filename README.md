# Taiwan Wildlife Explorer

原生 HTML / CSS / JavaScript ES modules，無第三方套件或建置步驟。沿用 `design-reference/` 三張版面圖的單頁雙區塊配置、深藍青綠視覺與單欄原位展開圖鑑。

## 本機啟動

```sh
python3 -m http.server 8000
```

開啟 http://localhost:8000 。請透過 HTTP 開啟，直接雙擊 HTML 可能受模組來源限制。

## 探索與座標

總覽使用 `assets/map/taiwan-ecological-map.png`，保持完整比例及透明度。滾輪／＋／− 縮放，拖曳移動，⌖ 重設。230% 起顯示約 26px 研究區入口，最高 350%；三區內均為全圖 100%、動物 180% 顯示、最高 250%。返回總覽保留原視野；重進區域回到全圖。地圖可視框依原圖比例計算，區域內限制平移，不露出圖片外部。

`regions.js` 是入口與區域動物座標的唯一正式設定，百分比以完整圖片左上角 (0,0)、右下角 (100,100) 為範圍。圖片為插畫，沒有地理校準，座標不代表經緯度或野外目擊點。

| 區域 | 總覽入口 X,Y | 區域動物 X,Y |
| --- | --- | --- |
| 山地森林 | 50,58 | bear 82.2,52.0；monkey 32.5,31.8 |
| 低海拔森林 | 44,30 | cat 25.0,35.9；magpie 12.0,5.4 |
| 高山溪流 | 63,29 | salmon 76.0,35.0（初始位置） |

入口依指定畫面關係安排；武陵實際上較銅鑼／通霄略南，溪流入口的右上方位置有示意性偏移。區域動物不在總覽重複出現。地圖插畫維持自然小尺寸，無名稱與固定光環，保留約 40px 點擊區、鍵盤名稱、首次掃描及小型確認標記。

## 圖鑑與研究照片

圖鑑依固定編號排序，未解鎖僅顯示編號、？？？、未知物種與尚未發現，無照片或資料且不可展開。解鎖後顯示真實照片、名稱、學名、分類、發現研究區與狀態；一次只展開一張，照片在左，研究資料在右。展開內容留在獨立捲動列表，不撐高頁面。

照片完全由使用者提供，預留路徑為 `assets/animals/photos/bear.png`、`monkey.jpeg`、`cat.jpg`、`magpie.jpg`、`salmon.jpg`。把照片放到對應路徑後重新整理即可，缺檔、損壞或尚未載入時顯示原風格占位區，不顯示破圖。圖鑑縮圖、展開照片與研究面板均使用 `object-fit: cover` 適應固定照片區塊，不更動地圖 2D 插畫。

照片路徑與預留作者／來源／授權欄位集中於 `scripts/data/photos.js`，透過 `animals.js` 的 `photo` 共用。實際署名與授權由使用者提供；未提供時不顯示或推測。先前下載照片與授權紀錄保留於 `assets/animals/photos/previous-downloads/`，不由介面引用。詳細提供方式見 [照片資料夾說明](assets/animals/photos/README.md)。

研究文字仍待確認：五種皆缺獨立食性、正式物種介紹、生態小知識與保育分級，欄位明示待補，未自行撰寫生態知識。棲地及活動習性沿用既有示範文字並標記待校核。可在 `animals.js` 填入 `diet`、`introduction`、`trivia`、`conservation` 等欄位，不建立第二份動物資料。

首次發現顯示「發現新物種！／動物名稱／已加入研究圖鑑」通知，2.8 秒後自動隱藏。重複點擊只顯示研究資料，不重複通知或增加紀錄。

## 進度保存

`state.js` 是唯一探索狀態來源。使用 localStorage 的 `twe.exploration.v1` 保存物種 ID、首次紀錄、發現研究區、最近選取與已造訪區域 ID；`twe.researcher.v1` 保存研究員名稱、固定編號與加入日期。重新整理會恢復圖鑑、紀錄、研究面板與地圖已發現標記，不重播首次通知。

研究員檔案中的重置需要確認，只清除探索進度，保留研究員稱呼。儲存損壞會安全退回，無效／重複 ID 會過濾；儲存被禁止或空間不足時，頁面仍可在記憶體中操作，研究員檔案會提示。本網站不使用後端或帳號系統。不同主機／連接埠有不同瀏覽器儲存空間。

## 研究員檔案 Phase 1

沿用原有入口與中央 Modal，桌面寬 640px、最高 80dvh。固定精簡身分列僅含剪影頭像、名稱、目前研究員稱號與展開箭頭。編號、加入日期、稱號及所屬計畫預設收合，展開內容位於下方獨立捲動區，不增加固定列高度；每次開啟回到頂端並收合。展開狀態不寫入儲存，箭頭具 aria-expanded／aria-controls／動態標籤，收合時詳細資料對輔助工具隱藏。小視窗時身分證必要內容也可捲動，極矮視窗提供整窗捲動退路。保留既有確認後重置探索功能，不加入虛構統計或徽章。

身分資料沿用 `twe.researcher.v1`，欄位為 `{ version: 1, name, id, joinedDate }`，不新增第二份研究員名稱或探索紀錄。編號及日期於第一次載入時補建，日期使用 Asia/Taipei；舊使用者若未存加入日期，無法倒推出歷史首次造訪日，會以首次載入此版本的日期補建。既有名稱保留，其他設定欄位也保留，不觸碰首次邀請旗標。原有超過 16 字元的名稱不會被自動截斷，往後儲存名稱時需符合新限制。

點名稱旁鉛筆可原位編輯，有即時字數、儲存與取消。驗證會移除前後空白、拒絕空白與超過 16 個 Unicode 字元的名稱；只有按儲存才更新資料。名稱使用 textContent／input.value，未當作 HTML。成功顯示局部「已儲存 ✓」約兩秒；瀏覽器無法保存時會明示僅保留本次頁面。取消或未儲存就關窗不會更新名稱。

開啟使用 200ms 淡入／96% 至 100% 縮放，關閉反向播放；尊重 prefers-reduced-motion。關閉動畫結束前仍維持背景鎖定，X、遮罩及 Esc 均沿用共用焦點／事件清理流程，不改變地圖視野。

`getResearcherProfile()` 提供身分資料；稱號由 Phase 2 的既有發現物種數量推導，統計內容置於下方捲動區，不影響精簡固定列。

人工驗收：開啟研究員檔案 → 編輯名稱並測試空白／超長／取消／儲存 → 檢查兩秒提示 → 重新整理確認 ID、日期與名稱 → 未儲存關窗再開 → 檢查下方捲動重設 → 在區域內開關確認地圖不變 → 在系統減少動態設定下重試。

## 研究員檔案 Phase 2

下方捲動區新增 2×2 統計卡與圖鑑圓環，以及桌面三欄兩列的六枚生態徽章。窄視窗徽章改兩欄；所有新樣式限於研究員內容與既有通知，不改動地圖、圖鑑、名字編輯或 Modal 焦點／動畫。

| 資料 | 唯一來源 |
| --- | --- |
| 已發現物種、圖鑑百分比、稱號 | `state.discovered` 的有效物種 ID |
| 已探索研究區域 | `state.visitedRegions` 的穩定區域 ID |
| 累積發現紀錄 | `state.records.length`，不另設計數器 |
| 徽章解鎖 | 上述物種與區域資料即時計算 |

稱號依不同物種數：0–1 見習研究員、2–3 野外觀察員、4 資深研究員、5 生態探索專家。精簡列與詳細資料同步顯示。六枚徽章分別要求首次發現、黑熊＋獼猴、石虎＋藍鵲、鮭魚、三區造訪與全五種。鎖定徽章也能點選查看條件；一次顯示一枚詳情，重點同一枚會收合，原生按鈕支援鍵盤。

**沒有新增 localStorage key。** `twe.exploration.v1` 新增 `visitedRegions` 陣列，僅使用 `mountain-forest`、`lowland-forest`、`alpine-stream`。圖片載入且區域切換成功後才記錄，重複進入去重。開發者座標模式不累積造訪。舊版本沒有真正造訪資料，會從空集合開始，必須再次實際進入；不從動物紀錄推測歷史造訪。百分比、稱號、徽章與通知佇列都不持久化。

`subscribeExploration()` 訂閱模組內的 `exploration:changed` 事件資料，理由包含 `species-discovered`、`species-selected`、`region-visited`、`records-updated`、`progress-reset`。實際新成果比較更新前後的推導狀態，才產生徽章／晉升通知。紀錄若經既有狀態修改，呼叫 `persistProgress()` 會保存並刷新統計，不當作新探索成果。重新整理透過載入狀態及初次渲染恢復畫面，不重播通知。

首次發現通知、徽章解鎖（含圖案、名稱與條件）、稱號晉升共用既有 `#toast` 的 FIFO 佇列，每則 2.8 秒，依序顯示不覆蓋。重複點選、重新開窗或載入舊進度不排入舊通知。保留原有簡易探索重置，清除物種／紀錄／區域造訪並取消待顯示通知，研究員身分與首次邀請旗標保留；未擴充 Phase 3 完整資料管理。

Phase 2 人工驗收：在正常模式實際進三區，確認區域數去重且重新整理保留；依序找到五種動物，確認百分比與稱號邊界；點選鎖定／解鎖徽章切換詳情；在最後一種動物同時達成多項條件時等候佇列依序顯示。檢查 0%／100% 圓環、三欄兩列徽章、窄視窗、鍵盤、減少動態設定，以及重開檔案不重播通知。瀏覽器自動化目前不可用，仍需人工視覺驗收。

Phase 3 已補上寄語、研究完成標記與完整資料管理，見下一節。

## 研究員檔案 Phase 3

在統計下方、徽章上方顯示「臺灣野生動物研究完成」，但只在有效物種全部解鎖且三區都實際進入時出現。只有圖鑑 100% 不算完成。徽章詳情後方顯示研究日誌寄語，依 0、1–2、3–4、5 種不同物種切換為指定文字。兩者都由 `getResearcherSummary(state)` 推導，即時更新、不儲存獨立旗標，載入既有完成進度時也不新增教學或通知。

最下方的原生「資料管理」收合區每次開窗預設收合，內含兩種不同操作：

- **重新開始探索**：保留原語意，僅清除物種、發現紀錄、區域造訪，保留名稱、編號、加入日期及首次通知旗標，仍有原有的確認步驟。
- **重置所有研究資料**：另開一次確認小視窗，明確告知不可復原，有「取消」與「確認重置」。取消、Esc 或點確認視窗外只關閉確認，不修改資料。確認後移除本專案鍵、清空記憶體探索狀態與待顯示通知，再重新載入網站；新的頁面產生新研究員身分、零進度並顯示原本首次邀請。

實際儲存鍵集中於 `scripts/project-storage.js` 的明確清單，完整重置只移除：

```text
twe.researcher.v1
twe.exploration.v1
wildlifeExplorer_introSeen
```

沒有新增持久化鍵，也不使用 localStorage.clear() 或廣泛前綴刪除。其他應用的鍵即使共用相似前綴仍保留。座標編輯暫存與地圖視野是記憶體資料，重新載入自然恢復。移除儲存時若失敗會嘗試還原、顯示錯誤且不重新載入；移除成功但導覽失敗時會明示請手動重新整理。刪除成功後停止舊頁面寫入，避免尚未完成的區域載入或名稱儲存重建舊資料。

確認視窗使用原生 dialog、獨立無障礙標籤及預設焦點「取消」，避免父 Modal 的 Tab 處理干擾。父視窗既有 640px／80dvh、固定精簡列、獨立捲動、200ms 動畫與關閉方式均保留。

人工驗收請在可捨棄的瀏覽器測試資料中執行完整重置：先檢查不同進度的寄語與 100%／兩區未完成狀態，再完成三區確認標記；展開資料管理並取消一次，確認原資料仍在，最後確認完整重置並檢查新名稱／ID／加入日期、零圖鑑／紀錄／區域及首次邀請。實際瀏覽器的原生收合、巢狀確認焦點、動畫與重新載入仍待人工驗收。

## 探索指南與首次邀請

首次造訪自動開啟「RESEARCH MISSION / 001」研究員任務邀請。可選「查看指南」或「直接探索」；X、遮罩、Esc 關閉也會記錄已處理。獨立儲存鍵為 `wildlifeExplorer_introSeen`，值為 `1`，不影響探索或研究員資料，探索重置也不會清除這個旗標。

指南可隨時由既有「探索指南」按鈕開啟，五步操作說明一次顯示，含編號、圖示、研究員小提醒及「開始探索」。指南與邀請重用同一個原生 dialog 容器，但內容與介面狀態各自獨立；不切換頁面或更動地圖。長內容在視窗內捲動，背景鎖定捲動且由原生模態使背景不可操作。Tab 焦點留在彈窗，關閉後返回觸發按鈕，當次事件監聽器由 AbortController 清理。

四種關閉方式：右上 X、底部「開始探索」、暗色遮罩、Esc。只有真正從遮罩按下並點擊遮罩才會關閉，內部點擊或從內部拖曳至外部不會誤關閉。

人工驗收：用新的瀏覽器設定檔首次造訪，或只移除 `wildlifeExplorer_introSeen` 鍵後重新整理；不必清除探索資料。分別測試兩個邀請選項、四種關閉方式、重新整理後不再邀請、指南手動重開、Tab／Shift+Tab、較小視窗內捲動，以及在區域中開關指南後地圖視野保持原狀。瀏覽器若禁止本機儲存，只能在當次頁面記住處理狀態。

指南提到的探索操作皆已實作；動物研究文案仍有待補資料，本次不新增生態內容。

## 開發者座標編輯

開啟 http://localhost:8000/?debugMap=1 ，進入任一區域後選擇動物，單擊地圖移動，拖曳只移動視野。可強制顯示動物、查看一位小數座標、複製設定片段。剪貼簿不可用時提供手動複製。

各區編輯結果分別保留於記憶體，重新整理清除，不寫回正式座標，不觸發研究或發現。確認後手動更新 `scripts/data/regions.js`。移除網址參數即可正常探索。

## 主要檔案

- `index.html`、`styles/main.css`：既定版面與樣式。
- `scripts/main.js`：初始化、研究與通知連動。
- `scripts/map.js`、`map-geometry.js`、`map-editor.js`：共用地圖與編輯器。

- `scripts/researcher-dashboard.js`：統計、圓環、完成標記、徽章、寄語及狀態訂閱。
- `scripts/researcher-data-management.js`：原有探索重置、完整重置與獨立確認視窗。
- `scripts/project-storage.js`：持久化鍵登記與精確移除。
- `scripts/notifications.js`：共用非阻擋式通知佇列。
- `scripts/exploration-guide.js`：五步指南、首次邀請內容與獨立邀請旗標。
- `scripts/encyclopedia.js`、`research-panel.js`、`dialogs.js`：圖鑑、研究面板、工具視窗。
